# Atlas specimen posters

The five WebP files are captured from this app's `FlameOrb` renderer and the
matching recipes in `orbPresets.ts`, using their default camera positions.
Captured 2026-09-24 in headed Chrome on an AMD RDNA 4 hardware WebGPU adapter.
They are not AI-generated concept images. The frame contains only the rendered
specimen against black; orbital guides, labels and other worlds are hidden.

The small satellites and the unavailable-WebGPU view use these static images.
The selected world replaces its poster after its first detailed live pass.
Regenerate the matching poster when changing a preset's geometry or palette.
The original renderer is stochastic, so later captures can vary slightly.
